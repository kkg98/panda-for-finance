# 🐼 Pandas for Finance

Personal learning repo for the Codecademy **Introduction to Pandas for Finance** course.

## What's in here

| Folder | Contents |
|--------|----------|
| `examples/` | Runnable `.py` files — one per concept/function |
| `notes/` | Markdown notes mirroring my OneNote entries |

## My learning approach

For every new concept I document:
1. **Why it exists** — what problem it solves in finance
2. **How it works** — plain language explanation
3. **Syntax** — the actual code signature
4. **Example** — a realistic finance scenario
